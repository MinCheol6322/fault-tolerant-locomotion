# Fault-tolerant Quadrupedal Locomotion — Project Page

Static project page for the anonymous 2026 submission.

## Preview locally

```bash
python3 -m http.server 8080 --directory website
```

Open <http://localhost:8080>.

## Content updates

- Replace `Anonymous Authors` and the BibTeX entry after the review period.
- Add paper/code/video links to the hero actions when available.
- Place compressed MP4 files in `assets/videos/` and add `<video>` elements to the real-robot cards.

## Deployment

The included GitHub Actions workflow publishes this folder to GitHub Pages on every push to `main`.
